# 行驶航向保持与到点调正

原来的 `TolYaw_deg` 同时作为到达容差和航向控制死区，默认 3°。因此，车子偏转约 1.78° 且不再转动时，控制器不再消除角度误差，并可结束 Run。

航向保持采用滞回：内阈值为 `min(0.5°, TolYaw_deg / 2)`，外阈值为内阈值的两倍且不超过到达容差。开始新目标时要求主动收敛至内阈值，进入后退出角度纠偏；只有超出外阈值才重新启动。默认对应 0.5°/1°，避免测量值在 0.5° 边缘波动时不断重启。完成一个点还必须在到达容差内、未处于主动纠偏阶段且不超出外阈值，并满足已有沉降条件。因此退出纠偏后允许在滞回带内小幅波动，并非每次结束都严格小于 0.5°；这不是实车绝对精度保证。

航向差分角速度用 30 ms 时间常数低通后参与阻尼和静止判断；对齐附近的静摩擦角速度地板逐渐减弱，不再突然施加完整补偿。容差圈内平移爬不动也不能绕过航向对齐。

该阈值在 `position_control.c` 的 `POSITION_HEADING_HOLD_MAX_DEG` 中定义，不新增 Flash 字段，不要求清空既有配置。Position 与 Route 共用这个控制器。用户 STOP、故障等主动停止行为仍会立即停机，不执行自动调正。

车子已到 XY 附近、航向尚未对齐，但有角速度命令而实测没有转动时，沿用两秒航向失速检测，报告故障，不能冒充到达成功。

航向控制的改动不改变轮速 PID、平移加速度、平移速度规划或里程计比例。新增仿真覆盖：正负 1.78° 在平移时纠偏、终点不提前成功、平移失速不绕过航向对齐、原地转不动故障、两侧偏差收敛，以及死区边缘波动不重复启动。

上板记录应包含 `goal_yaw_deg,yaw_error_deg,nav_yaw_deg,cmd_omega_radps,pos_status,run`，并将实车车头方向与导航 Yaw 对照。若实车歪而导航 Yaw 显示已正，这项控制修改无法补偿估计误差。若导航知道有偏差、命令也在纠偏，而实际不转，应排查轮速跟踪和执行能力。

里程计已经用估计航向将车体系位移旋转到世界系。实际偏航但估计准确，并不必然使距离算错；估计航向误差和轮子滑移才会造成坐标积分误差。航向估计错 5° 时，1 m 位移可能产生约 8.7 cm 的横向投影误差，不能把它直接当作纵向距离少算 8.7 cm。
