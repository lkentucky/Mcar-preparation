# S 曲线规划与里程计校准

## 当前控制结构

`scurve_profile.c` 生成七段 jerk 受限的直线参考：起始速度取当前世界系实测速度在目标方向上的非负投影，末速度为零。短距离会降低峰值速度、压缩或取消部分阶段；无需反复逐周期重建整段规划。

`position_control.c` 每 10 ms 采样参考位置与速度，输出“参考速度 + 有界的位置/速度误差纠偏”，再转为车体系并进入已有麦轮逆解、四轮速度闭环。单点 Position 和多点 Route 使用同一个位置控制器，因此路线节点自动使用 S 曲线。

曲线时间结束后进入低速终点纠偏，仍需要实际 XY/Yaw 容差、低实测速度、输出归零且稳定 0.2 s 才报到达。车被挡住不会只因为计时结束就切换节点。运行中修改目标或速度/加速度/jerk 约束会从当前位姿重新规划；如果短距离不足以容纳当前初速的完整刹车段，则退回有界低速制动/终点纠偏。

原有 X/Y 积分项没有增加。位置纠偏使用现有 XY_Kp、XY_Kd；单独限制纠偏速度，避免重新用远处终点的大误差覆盖整个规划过程。逐点停车，尚未实现不停顿的平滑过点。

## 调节与观察

- `Position/MaxV_cmps`：参考速度上限，默认 20 cm/s。
- `Position/Acc_cmps2`：参考加速度上限，默认 40 cm/s²。
- `Position/Jerk_cmps3`：参考 jerk 上限，默认 120 cm/s³，允许 1～3000。越小，加速/减速力度变化越缓，行程用时通常越长。
- `Position/RefV_cmps`、`Phase`：当前规划参考速度与阶段。阶段 1～7 为执行曲线，8 为曲线结束，0 为无有效曲线/制动回退。

通过现有 WiFi 滑杆格式调节：

```text
[slider,pos_max_jerk_cmps3,120]
```

可订阅的新增遥测：`ref_x_cm,ref_y_cm,ref_speed_cmps,ref_accel_cmps2,profile_elapsed_s,profile_total_s,profile_phase`。例如：

```text
SUB x_cm,y_cm,ref_x_cm,ref_y_cm,ref_speed_cmps,cmd_vx_cmps,cmd_vy_cmps,profile_phase
```

S 曲线严格约束的是规划参考。叠加实测纠偏后，最终指令仍经过原有速度/加速度限制，但不能把参考 jerk 上限当作最终 PWM 或实际车辆 jerk 的保证。

## 校准操作

校准公式：`新 Scale = 旧 Scale × |真实尺量距离 / 当前里程计距离|`。比例作用于车体前向/左向里程计，然后再用 IMU 航向转换到固定坐标；不修改原始编码器计数、DR 的分辨率归一化或轮速 PID 单位。

1. 在测试起点停止车辆，执行 Navigation/Zero，等待 Valid、Bias 就绪。
2. 保持车头朝向 Zero 的方向，单独沿 X 前进或 Y 横移，完成一次至少 10 cm 的直线测试；不要同时转向或斜走。
3. 停稳、关闭 Position/Run 和 Route/Run，用尺量出真正走过的距离。
4. X 测试将尺量距离输入 `Navigation/RealX_cm`，然后将 `CalX` 置 On；Y 测试用 `RealY_cm/CalY`。数值为距离大小，单位 cm。
5. `CalState=1` 表示成功。Scale 更新后会自动重建当前点为新 Zero，等待定位重新就绪再测试；需要回到原测试起点时，再手动定位到起点并 Zero。
6. 确认单轴与斜向实际距离后执行 `SaveCfg`，保存比例、S 曲线参数和路线。

校准只允许停车且定位有效时进行。朝向偏离 Zero 超过 3°、横向偏移超过主方向的 10%（至少允许 2 cm）、速度超过 3 cm/s、距离过短或新 Scale 不在 0.1～5 范围时拒绝。

`CalState`：1 成功，-1 距离/比例非法，-2 Run 或 Route 未关闭，-3 定位未就绪，-4 方向/运动状态不适合校准。

也可从上位机发送换行文本 `CAL X 实际距离_cm` 或 `CAL Y 实际距离_cm`。固件自动使用当前 Zero 坐标的里程计读数；成功应答为 `MCAR CAL X 新比例`，失败为 `MCAR ERR ...`。这只是固件解析接口，没有改动上位机界面。

当前已有的默认比例 **0.97 / 1.04** 和硬件参数沿用本地工程。没有复制 bestway 另一辆车的距离/串轴补偿表，也没有再次叠加相同的比例修正。先检查轮径、减速比、逐轮方向/分辨率，再用实测校准。

## 保存兼容与验证范围

Flash 格式升级为 v3：在 v2 路线字段之后追加 jerk，54 个 32 位字。v1/v2 的原参数继续读取，v2 的路线也继续恢复；旧格式缺少 jerk 时取 120。恢复配置不会自动开 Run。

主机验证包括七段曲线积分距离、速度/加速度/jerk 上限、带初速、短距制动回退、平移与旋转收敛、横向扰动纠偏、堵转不误报到达、连续节点切换、真实编码器/IMU适配的校准，以及 v1/v2/v3 Flash 兼容。实车滑移、摩擦和电机跟踪能力仍需用遥测和尺量验证。
